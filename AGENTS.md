# Classic CPS source release

This repository publishes the current RFKV-only Classic CPS snapshot. The
selected development source owns the common format/model code. Refresh this
snapshot only through reviewed source commits and its exact payload manifest;
do not create a second independently maintained data model. No old Classic
A5/D/E import, writer, draft conversion or separate legacy CPS is supported.
Firmware owns the stored format; validate with its actual C encoder/decoder.
Preserve MIT notices and upstream credits. Publishing and site deployment
require an explicit user request. No physical radio access follows from tests.
