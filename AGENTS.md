# Classic CPS source release

This repository stages the currently live legacy-format Classic CPS initial
source release. Preserve runtime hashes in LIVE-SNAPSHOT.json. Do not import
unreleased RFKV migration changes, Next-specific source, private data or
research history into this initial release. Classic firmware owns the stored
format; cross-check changes against its actual C encoder/decoder. Preserve MIT
notices and upstream credits. Build and package locally only; publishing and
site deployment require an explicit user request.
